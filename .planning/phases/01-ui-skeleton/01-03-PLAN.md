<task type="auto">
  <name>Task 1: Header and request panel</name>
  <files>web/src/components/app-header.tsx, web/src/components/request-panel.tsx</files>
  <action>
**app-header.tsx** → `export function AppHeader()` (no props). Reads appConfig. Renders a `<header>` with `appConfig.name` (h1, text-xl font-semibold) and `appConfig.tagline` (muted). If `appConfig.sponsors.length > 0`: right-aligned "Powered by" label + each sponsor as `<img src={logo} alt={name} className="h-6 w-auto">` when logo exists, else the name text; wrapped in `<a href={url} target="_blank" rel="noreferrer">` when url exists. When empty: render nothing for the strip. Bottom border via Separator or border-b.

**request-panel.tsx** → `"use client"`; `export function RequestPanel(props: { status: RunStatus; query: string; onRun: (q: string) => void; onReset: () => void })`. Card with title "Request". Local `useState` draft initialised from props.query. `<label>` (appConfig.requestLabel) bound to a Textarea (placeholder appConfig.requestPlaceholder, rows 4, maxLength 2000, disabled while running). Submit on button click and on Ctrl/Cmd+Enter. Example prompts: small outline Buttons from appConfig.examplePrompts; click sets draft and calls onRun(prompt); disabled while running. Primary Button: label "Run agent" or "Running…" while running; disabled when draft.trim() is empty or running. When status is "done" or "error": a ghost "New request" Button that clears draft and calls onReset.

<task type="auto">
  <name>Task 2: Candidates panel and decision card</name>
  <files>web/src/components/candidates-panel.tsx, web/src/components/decision-card.tsx</files>
  <action>
**decision-card.tsx** → `"use client"`; `export function DecisionCard(props: { decision: Decision; candidate?: Candidate; action: ActionState; onApprove: () => void })`. Card highlighted with `border-primary`. Title "Agent recommendation"; body decision.summary; if candidate: title, vendor, formatted price. `label = decision.actionLabel ?? appConfig.actionLabel`.
States by `action.status`:
- idle: primary Button `{label}` opens a Dialog (controlled `open` state). Dialog title "Confirm action"; description `The agent will {label.toLowerCase()} for "{candidate?.title ?? decision.candidateId}"{price ? ` at {price}` : ""}. This is recorded in the audit trail.`; footer: "Cancel" (closes) and "Confirm" (closes, calls onApprove).
- pending: disabled Button "Working…".
- success: Alert (default variant) titled "Done" showing result.message and "Reference: {result.reference}" when present.
- error: Alert variant "destructive" titled "Action failed" with action.message + outline Button "Retry" calling onApprove.
Price formatting: `new Intl.NumberFormat(undefined, { style: "currency", currency: c.currency }).format(c.price)`.

**candidates-panel.tsx** → `export function CandidatesPanel(props: { status: RunStatus; candidates: Candidate[]; decision?: Decision; action: ActionState; onApprove: () => void })`. Section heading "Candidates".
- If decision: render `<DecisionCard decision candidate={candidates.find(c => c.id === decision.candidateId)} action onApprove />` above the grid.
- Empty (status idle and no candidates): dashed-border block: "Candidates the agent considers will appear here, each with the reason it was picked or rejected."
- Running with no candidates: 3 Skeleton cards.
- Error with no candidates: muted text "No candidates were found before the run stopped."
- Grid `sm:grid-cols-2 xl:grid-cols-3` of Cards: optional image (`<img>` with alt=title, `aspect-video object-cover`), title (line-clamp-2; link with target _blank if url), vendor (muted), price, attributes as a `<dl>` of key/value rows, verdict Badge with TEXT label: selected → default variant "Selected"; rejected → destructive (or outline if destructive missing) "Rejected"; considering → secondary "Considering"; reason line below (muted) when present. Rejected cards get `opacity-70`; the selected card gets `ring-2 ring-primary`.

<task type="auto">
  <name>Task 3: Audit trail timeline with JSON export</name>
  <files>web/src/components/audit-trail.tsx</files>
  <action>
`"use client"`; `export function AuditTrail(props: { state: RunState; action: ActionState })`. Card with title "Audit trail" and header-right outline Button "Export JSON" (lucide Download icon), disabled when `state.events.length === 0`.
Export: `const payload = { query: state.query, startedAt: state.startedAt, exportedAt: new Date().toISOString(), events: state.events, action }`; `new Blob([JSON.stringify(payload, null, 2)], { type: "application/json" })`; object URL; temporary `<a download={\`audit-${new Date().toISOString().replace(/:/g, "-")}.json\`}>` click; revoke URL.
Body: ScrollArea (height `lg:h-[calc(100vh-12rem)]`, `h-96` below lg) containing an `<ol aria-live="polite">` timeline. Each step item: lucide icon by kind (plan → ListChecks, search → Search, fetch → FileText, compare → Scale, decide → CircleCheck, act → ShoppingCart); title; time `new Date(step.at).toLocaleTimeString()`; status Badge with text (running → secondary "Running" + Loader2 animate-spin icon; ok → outline "OK"; warn → secondary "Check"; fail → destructive "Failed"); detail (muted, text-sm); sources as small chips: link (target _blank, rel noreferrer) when url, plain text otherwise. A vertical line connects items (border-l on the list).
Auto-scroll: a sentinel div with ref; `useEffect` on `state.steps.length` → `scrollIntoView({ block: "nearest" })`.
States: idle with no steps → muted copy "Every step the agent takes, and the source it used, is logged here."; running → after the list, a muted "Agent is working…" row with spinner; error → destructive Alert "Run stopped" with state.error; done → muted line `{state.steps.length} steps logged`.
