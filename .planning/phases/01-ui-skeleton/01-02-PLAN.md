Both files: `export const dynamic = "force-dynamic";` Node runtime (do NOT export `runtime = "edge"`). Export only `POST(req: Request)`.

**agent/route.ts**:
1. Parse `await req.json()` in try/catch → on failure `Response.json({ error: "Body must be JSON" }, { status: 400 })`.
2. `query` = body.query if string, trimmed; if empty or > 2000 chars → 400 `{ error: "query must be a non-empty string of at most 2000 characters" }`.
3. `const upstream = process.env.AGENT_BACKEND_URL;` if set: `try { const r = await fetch(upstream + "/agent", { method: "POST", headers: { "content-type": "application/json" }, body: JSON.stringify({ query }), signal: req.signal }); return new Response(r.body, { status: r.status, headers: { "content-type": r.headers.get("content-type") ?? "application/x-ndjson", "cache-control": "no-store" } }); } catch { return Response.json({ error: "Agent backend unreachable" }, { status: 502 }); }`
4. Else pull-based stream: `const it = runMockAgent({ query }); const enc = new TextEncoder();` `new ReadableStream<Uint8Array>({ async pull(c) { try { const { value, done } = await it.next(); if (done) c.close(); else c.enqueue(enc.encode(JSON.stringify(value) + "\n")); } catch (e) { c.enqueue(enc.encode(JSON.stringify({ type: "error", message: "Mock agent crashed" }) + "\n")); c.close(); } }, cancel() { void it.return(undefined); } })` returned with headers `content-type: application/x-ndjson; charset=utf-8` and `cache-control: no-store`.

**action/route.ts**: parse JSON (400 on failure); require non-empty string `candidateId` and `query` (400 `{ error: "candidateId and query are required" }`); if AGENT_BACKEND_URL set → POST to upstream + "/action", return `new Response(r.body, { status: r.status, headers: { "content-type": "application/json" } })`, 502 on throw; else `Response.json(runMockAction({ candidateId, query }))`.

<task type="auto">
  <name>Task 3: useAgentRun client hook</name>
  <files>web/src/hooks/use-agent-run.ts</files>
  <action>
`"use client";` Imports: useCallback, useEffect, useRef, useState from react; applyEvent from "@/lib/agent/reduce"; types + initialRunState from "@/lib/agent/types".
`export function useAgentRun(): { state: RunState; action: ActionState; run(query: string): void; reset(): void; approve(): void }`.
- State: `useState<RunState>(initialRunState)`, `useState<ActionState>({ status: "idle" })`, `abortRef = useRef<AbortController | null>(null)`, `stateRef` mirroring latest state (updated in an effect) for approve().
- `fail(message)` helper: `setState(s => ({ ...s, status: "error", error: message }))`.
- `run(query)`: trim; ignore if empty. Abort previous; new AbortController; `setState({ ...initialRunState, status: "running", query, startedAt: new Date().toISOString() })`; `setAction({ status: "idle" })`. Then async IIFE:
  fetch("/api/agent", POST JSON {query}, signal). If !res.ok: read `(await res.json().catch(() => null))?.error ?? \`Agent request failed (${res.status})\`` → fail; return. If !res.body → fail("Agent returned no data").
  Reader loop with TextDecoder({stream:true}); buffer; split on "\n"; keep last partial; for each non-empty line: JSON.parse in try → on throw fail("Malformed event from agent"), abort, return; `setState(s => applyEvent(s, ev))`; track `terminal = ev.type === "done" || ev.type === "error"`. After loop, process any remaining buffered line the same way. If no terminal → fail("Agent stream ended unexpectedly").
  catch: if signal aborted → return silently; else fail("Could not reach the agent").
- `reset()`: abort; setState(initialRunState); setAction idle.
- `approve()`: read stateRef; if no decision → return. setAction pending; POST /api/action {candidateId: decision.candidateId, query}. Non-OK → error message from JSON `error` or `Action failed (${status})`. OK → `result: ActionResult`; `setState(s => applyEvent(s, { type: "step", step: result.step }))`; `setAction(result.ok ? { status: "success", result } : { status: "error", message: result.message })`. Network throw → error "Could not reach the action endpoint".
- Unmount effect aborts the in-flight run.
Note: applying the action step appends a "step" event; status stays "done" because applyEvent only changes status on done/error.
